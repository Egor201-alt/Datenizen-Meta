# Datenizen Meta (Documentation)

This repository hosts the official documentation for [Datenizen](https://github.com/Egor201-alt/Datenizen) - a database addon for [Denizen](https://github.com/DenizenScript/Denizen).

📖 **[Read the docs](https://egor201-alt.github.io/Datenizen-Meta)**

---

Built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material). Deployed automatically on every push to `main` via GitHub Actions.

### Local Preview

```bash
pip install mkdocs-material
mkdocs serve
```

Then open [http://localhost:8000](http://localhost:8000).
